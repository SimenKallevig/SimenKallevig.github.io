# KallTech website

## Updating Headlinr

Headlinr content and configurable values are in `headlinr/index.html`; its dedicated styles are at the end of `css/style.css`.

- Search for `apps.apple.com` and `play.google.com` to update store links.
- Replace Headlinr files in `assets/` to update screenshots.
- Founder photo: `assets/Founder_photo.jpeg`.
- Download QR code: `assets/headlinr_qr.png`.
- App Store screenshots: `assets/Apple iPhone 16 Pro Max Screenshot 1.png` through `5.png`.
- Update `.hl-metrics` when verified API statistics are available. Add only approved testimonials.
- Artist and organizer buttons currently lead to Support; replace these when dedicated pages exist.
